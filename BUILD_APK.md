# Build the APK

This is the Android wrapper for Prakash Kirana Stores Voice Billing V2.

## Fastest route
Upload this entire project to GitHub and use GitHub Actions/Android Studio to build.

Android Studio:
1. Open this folder.
2. Let Gradle sync.
3. Build > Generate App Bundles or APKs > Generate APKs.
4. Install the generated `app-debug.apk`.

The app requests microphone permission for voice billing.
